Guide de Configuration Cloudflare & Domaine

Comment associer votre domaine tunnel.corelabs.network avec Cloudflare Tunnels.

1

Ajouter le domaine dans Cloudflare

Ajoutez votre nom de domaine sur votre compte Cloudflare et pointez vos serveurs de noms (NS) vers Cloudflare.

2

Créer un enregistrement DNS Wildcard

Dans la zone DNS Cloudflare, créez un enregistrement CNAME wildcard : Nom * vers la cible du serveur de tunnel CoreLabs.

3

Token API & Cloudflare Tunnel Token

Générez un Token API Cloudflare avec l'autorisation Zone.DNS:Edit et renseignez les variables d'environnement dans le serveur backend :

CLOUDFLARE_API_TOKEN="votre_token"
CLOUDFLARE_ZONE_ID="votre_zone_id"
DOMAIN_NAME="tunnel.corelabs.network"
